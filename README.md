IT Support Multi-Monitor Troubleshooting Case Study
Overview
This project documents the investigation and diagnosis of a multi-monitor display issue in a simulated IT support environment.

Problem
A user reported that a second monitor displayed a "No Signal" message despite previously working correctly.

Investigation
Reviewed the incident ticket and user-reported symptoms.
Accessed the workstation remotely.
Verified monitor, cable, and port functionality.
Analyzed Windows display settings.
Reviewed hardware and configuration documentation.
Identified that the system was using a Basic Display Adapter and could not detect the second monitor.
Root Cause
The issue was traced to a graphics/display driver problem that prevented multi-monitor functionality.
